CSS Box Model Exploration

Understanding how content, padding, border, and margin work together.

Default: box-sizing: content-box;

Content Box

Here, the total size of the element is the content width + padding + border. The box expands as padding and borders are added.

Using: box-sizing: border-box;

Border Box

With border-box, padding and border are included in the total width and height. The element stays the same size no matter how much padding or border you add.
